# Research Hub 주요 기능 소개

조사·설문 운영에 AI를 접목한 Research Hub의 **핵심 차별 기능**을 소개합니다.

---

## 한눈에 보기

| 기술 | 역할 |
|------|------|
| **KSIC 매핑·RAG 엔진** | 한국표준산업분류(KSIC) 코드·업종 지식을 검색·검증해, AI 설문 설계에 **산업 맞춤 맥락**을 주입 |
| **AXI (Advisor Agent)** | 공개 사이트에서 조사원·직원이 용어·보기·스크립트를 바로 물어볼 수 있는 **현장 가이드 AI** |

두 기능은 서로 연결됩니다. 설문에 KSIC가 부여되면 AXI는 그 업종 맥락을 참고해 답하고, KSIC 엔진이 쌓아 둔 산업 지식은 AI 설문 생성에도 동일하게 활용됩니다.

---

## 1. KSIC 매핑 엔진 + RAG 기반 산업 맥락

### 무엇을 해결하나요?

일반 AI에게 “설문을 만들어 달라”고만 하면, **업종 특성이 흐려진 범용 문항**이 나오기 쉽습니다.  
Research Hub는 **KSIC(한국표준산업분류) 코드**를 설문·생성 파이프라인의 중심에 두고, 해당 산업에 맞는 조사표를 설계하도록 설계했습니다.

### 독창적 접근: 매핑 + RAG

Research Hub는 다음을 하나의 흐름으로 묶었습니다.

1. **KSIC 코드 매핑 엔진**  
   - 관리자가 설문·AI 생성 시 KSIC 코드·업종명을 지정  
   - 내부 KSIC 계층 DB와 **외부 산업 분류 스냅샷**을 대조해 코드 유효성을 검증  
   - 잘못된·미동기화된 코드로 설문이 나가지 않도록 게이트 역할

2. **RAG 방식의 지식 주입**  
   - 선택한 코드에 대해 DB에서 **산업 정의·경로·AI용 상세 컨텍스트**를 검색(Retrieval)  
   - 검색된 업종 지식을 프롬프트에 붙여 LLM이 설문안을 생성(Augmented Generation)  
   - 결과적으로 “일반론 설문”이 아니라 **해당 KSIC에 맞춘 문항·근거·CATI 멘트**를 산출

```
[관리자 입력: KSIC 코드·조사 목적]
        ↓
[매핑 엔진: 코드 검증 · 외부 스냅샷 대조]
        ↓
[RAG: 업종 AI 컨텍스트·계층 정보 검색]
        ↓
[LLM: 산업 맞춤 설문안 · 스크립트 초안]
```

### 현장에서 느껴지는 효과

- AI 설문 생성 시 **업종 적합성(ksicRelevance)**·문항 근거가 산업 맥락을 반영
- 설문에 저장된 KSIC는 이후 **AXI 현장 안내**에도 재사용
- 코드·명칭·상세 지식을 DB로 관리해, 모델만 바꿔도 **동일한 산업 지식 레이어**를 유지

## 2. AXI — Advisor Agent

### 무엇을 해결하나요?

전화·온라인 조사 중에는 용어 뜻, 보기 해석, 스크립트 표현을 **즉시** 확인해야 하는 순간이 많습니다.  
AXI는 조사원·직원이 공개 사이트 어디서든 짧게 물어보고, **1~2문장으로 바로 쓸 수 있는 답**을 받는 Advisor Agent입니다.

### 주요 특징

| 항목 | 내용 |
|------|------|
| **전역 플로팅 UI** | 공개 홈·설문 광장·문의·CMS 등에서도 아이콘으로 호출 (드래그로 위치 이동) |
| **설문 맥락 모드** | 설문 참여 화면에서는 해당 설문의 **제목·KSIC·업종·스크립트·문항**을 참고해 답변 |
| **일반 안내 모드** | 설문 밖에서는 사이트·조사 용어에 대한 **보편적 안내** |
| **권한 설정** | 총관리자가 홈페이지 관리 → 기타 관리에서 **비로그인·게스트·직원 등** 사용 대상을 체크 |
| **브랜드 아이콘** | 동일 메뉴에서 AXI 아이콘 이미지를 교체 가능 |

### KSIC와의 연결

설문이 KSIC를 갖고 있으면 AXI는 매핑·RAG 엔진이 만든 **업종 맥락**을 우선 참고합니다.  
같은 단어라도 “이 조사의 산업”에 맞는 해석을 유도해, **현장 가이드와 설문 설계 지식이 한 축**으로 이어집니다.

### 사용 이미지 (한 줄 요약)

> 조사원이 설문 화면에서 AXI를 열고 “이 보기 뜻은?”을 물으면,  
> 해당 설문의 KSIC·스크립트를 바탕으로 짧은 가이드가 돌아온다.

## 3. 두 기술이 만드는 가치

```
        ┌─────────────────────────┐
        │  KSIC 매핑 · RAG 엔진   │
        │  (산업 지식 · 코드 검증) │
        └───────────┬─────────────┘
                    │
        ┌───────────┴─────────────┐
        │                         │
        ▼                         ▼
┌───────────────┐         ┌───────────────┐
│ AI 설문 생성  │         │ AXI Advisor   │
│ 업종 맞춤 설계 │         │ 현장 즉시 안내 │
└───────────────┘         └───────────────┘
```

- **설계 단계**: KSIC RAG로 “어떤 산업에 맞는 설문인가”를 기술적으로 고정  
- **현장 단계**: AXI로 “지금 이 문항·보기를 어떻게 설명할까”를 즉시 지원  
- **운영 단계**: 권한·아이콘·설문별 KSIC를 관리자 화면에서 통제

Research Hub는 단순 챗봇 연동이 아니라, **한국 산업분류(KSIC)를 중심으로 한 매핑·검색 증강(RAG) 파이프라인**과, 그 지식을 현장에서 꺼내 쓰는 **Advisor Agent(AXI)** 를 하나의 플랫폼에 결합한 점이 핵심입니다.
