## 4) 제품의 작동원리(구조) 및 사용 프로그램

### 붙여넣기용 본문

본 제품은 웹 브라우저에서 동작하는 **조사·설문 통합 플랫폼**이다. 관리자가 한국표준산업분류(KSIC) 코드를 검색·분류표로 직접 선택한 뒤 조사 목적(메모)을 입력하면, 시스템이 해당 업종 지식을 조회(RAG형)하고 외부 KSIC 스냅샷으로 코드를 검증한 다음, 생성형 AI가 **산업 맞춤 설문지 3안**을 산출한다. 채택된 설문은 공개 웹 참여와 CATI(전화조사)로 배포되며, 현장에서는 Advisor Agent(AXI)가 해당 설문의 KSIC·문항·스크립트를 참고해 짧은 안내를 제공한다.

**작동 구조(계층)**

1. 이용 채널: 공개 웹(응답자·조사원) / 관리자 콘솔  
2. 응용 계층: Next.js 서버 액션으로 권한·입력값을 검증한 뒤 설문 생성·저장·응답 수집을 처리  
3. 지식·검증 계층: 내부 KSIC DB에서 업종 정의·계층·AI 컨텍스트를 검색하고, 공공데이터(한국무역보험공사 업종등급목록) 스냅샷과 코드를 대조  
4. 생성 계층: OpenAI 또는 Gemini LLM이 검색된 업종 맥락을 바탕으로 설문 3안·근거·보완 질문을 생성  
5. 데이터 계층: Supabase(PostgreSQL)에 설문·문항·응답·표본·권한·사이트 설정을 저장(RLS·역할 기반 접근)

**핵심 처리 흐름**

KSIC 검색·선택 → 조사 목적 메모 입력 → 외부 KSIC 매칭 검증 → 업종 지식 조회(RAG형) → AI 설문 3안 생성 → 근거·보완 질문 확인 후 설문 채택 → 배포·응답 수집·분석 / AXI 현장 안내

구조도 첨부 시: `docs/presentation/01-system-architecture.png`

## 5) 주요 기능 및 특징(기존제품과의 차별성 등)

### 붙여넣기용 본문

**주요 기능**

- KSIC 데이터 구조화 및 검색·연관 검색·분류표 선택  
- 한국무역보험공사 KSIC 코드 매칭 검증  
- RAG형 업종 지식 조회 기반 **AI 설문지 자동 생성(최대 3안)**  
- 추천 근거·보완 질문·예외(코드 불일치 등) 안내  
- 기본 웹 플랫폼: 사업·조사 정보 입력, 설문 참여, 결과 확인, 관리자 콘솔  
- CATI(전화조사) 표본 배치·컨택 결과·응답 스크립트  
- AXI(Advisor Agent): 공개 사이트·설문 화면에서 용어·보기·스크립트 즉시 안내  
- 응답 분석(문항별 빈도 그래프), 엑셀 내려받기, 응답 백업

**특징 및 기존 제품과의 차별성**

일반 설문 도구(구글 폼, 네이버 폼, SurveyMonkey 등)는 문항을 사람이 직접 만들며, **한국 산업분류(KSIC) 지식과 코드 검증이 없다.** 범용 챗봇(ChatGPT 등)에 “설문을 만들어 달라”고만 요청하면 업종이 흐려진 문항이 나오기 쉽고, 선택한 코드가 공식 분류와 일치하는지도 확인하지 못한다.

본 제품은 ① 관리자가 KSIC를 **직접 선택**하고, ② 내부 업종 지식을 **검색·주입(RAG형)** 하며, ③ 공공 업종목록으로 **코드를 검증**한 뒤, ④ 조사 설계 초점이 다른 **설문 3안**을 한 번에 제시한다. 같은 KSIC 맥락은 현장 AXI 안내에도 재사용되어, **설문 설계와 조사 현장이 하나의 산업 지식 축으로 연결**된다. 또한 웹 설문·CATI·사이트 CMS·권한 관리를 한 플랫폼에서 운영할 수 있어, 기존에 설문 작성·전화조사·홈페이지를 따로 쓰던 방식 대비 업무 단절이 줄어든다.

| 비교 항목 | 기존 범용 설문·챗봇 | 본 제품(Research Hub) |
|-----------|---------------------|------------------------|
| 산업 맥락 | 없음 또는 자유 텍스트 | KSIC 코드 중심, 업종 지식 검색(RAG형) |
| 코드 신뢰성 | 검증 없음 | 무역보험공사 KSIC 스냅샷 대조 |
| 설문 산출 | 1회성 초안 또는 수작업 | 설계 방향이 다른 3안 + 근거·보완 질문 |
| 현장 지원 | 별도 매뉴얼·메신저 | AXI가 해당 설문 KSIC·스크립트 기준으로 즉시 안내 |
| 조사 운영 | 웹 설문만, 또는 CATI 별도 시스템 | 웹 참여 + CATI + 관리·분석을 단일 플랫폼 |

## 칸이 좁을 때 (초단문)

**3)** 웹 소프트웨어 대표화면(공개 플랫폼 홈). 하드웨어 외관 없음.

**4)** 관리자가 KSIC를 선택하고 조사 목적을 입력하면, 시스템이 업종 지식을 조회·검증한 뒤 AI가 설문 3안을 생성한다. 사용 프로그램: Next.js, React, TypeScript, Supabase(PostgreSQL), OpenAI/Gemini, 공공데이터포털 KSIC API.

**5)** KSIC 매핑·외부 검증·RAG형 설문 3안 생성과 AXI 현장 안내를 한 플랫폼에 결합한 점이 차별점이다. 범용 설문 도구·챗봇은 한국 산업분류 검증과 조사 현장 연계가 없다.
