# 과업 현황 슬라이드용 문장

발주자 합의: **KSIC 검색·선택 → 메모 입력 → AI 설문 3안 생성**(외부 KSIC 검증 포함)이 목표 운영 방식.

아래 두 톤 중 PPT 목적에 맞는 버전을 사용하세요.

---

## 버전 A — 「개발 100% / 검수·인계만 남음」

강조: 기능은 끝났다. 남은 건 시험·제출·인계 절차.

### A-1. 현황 한 장 (핵심 메시지)

**제목:** 개발 현황 요약

**본문:**
- 과업 범위의 **핵심 기능 개발을 완료**하였습니다.
- KSIC 선택·검증부터 AI 설문 3안 생성까지 **발주자 확정 흐름이 정상 동작**합니다.
- 남은 과업은 **표준 시험·검수 및 산출물 인계**입니다.

**하단 한 줄:**  
기능 개발 완료 · 시험·검수·인계 진행

### A-2. 완료 범위

**제목:** 개발 완료 범위

**불릿:**
- KSIC 데이터 구조화 및 검색·분류표 선택
- 한국무역보험공사 KSIC 매칭 검증
- KSIC 매핑 기반 AI 설문지 자동 생성(3안)
- 추천 근거·보완 질문·예외 안내
- 내부 운영용 기본 웹 플랫폼(입력·결과 확인·관리)

### A-3. 남은 일정

**제목:** 잔여 과업

**불릿:**
- 표준 테스트 시나리오 수행 및 보정
- 최종 검수 대응
- 소스·DB·배포·복구 산출물 인계

**발표 멘트(30초):**  
“지시서상 핵심 기능은 모두 구현되었고, 발주자께서 원하신 KSIC 직접 선택 후 설문 3안 생성 방식도 확인받았습니다. 앞으로는 시험·검수와 인계에 집중하겠습니다.”

### A-4. 표지/마무리용 짧은 문장

- 표지 부제: `기능 개발 완료 · 검수·인계 단계`
- 마무리: `개발은 완료되었습니다. 시험과 인계로 과업을 마무리하겠습니다.`

## 버전 B — 「개발 완료 + 문서·인계 정리」

강조: 기능은 끝났고, 문서화·대체 합의·인계를 깔끔히 닫는다. (지시서 문구와의 정합성까지 챙기는 톤)

### B-1. 현황 한 장 (핵심 메시지)

**제목:** 개발 현황 요약

**본문:**
- **발주자 확정 기능 범위**의 개발을 완료하였습니다.
- KSIC 직접 선택 → 메모 입력 → AI 설문 3안 생성이 **목표 운영 방식**으로 확정·검증되었습니다.
- 잔여는 **시험·검수**, **구성·범위 문서 정리**, **산출물 인계**입니다.

**하단 한 줄:**  
기능 개발 완료 · 문서·시험·인계 정리

### B-2. 완료 범위

**제목:** 개발 완료 범위 (합의 기준)

**불릿:**
- KSIC 구조화·검색·선택 및 외부 코드 매칭 검증
- RAG형 지식 조회(업종 컨텍스트) 기반 설문 생성
- 복수 설문안(최대 3)·근거·보완 질문 제공
- 기본 플랫폼: 사업·조사 정보 입력, 결과 확인, 데이터 관리 화면
- 반응형 웹·형상관리(Git)·인증·입력 검증 등 기본 품질 요건

### B-3. 범위 확정 (지시서 해석)

**제목:** 운영 방식 확정

**본문:**
- KSIC 코드는 **검색·연관 검색·분류표로 관리자가 직접 선택**합니다.
- 선택·메모 입력 후 AI가 **산업 맞춤 설문지 3안**을 생성합니다.
- 비정형 문장만으로 KSIC 코드를 자동 추천하는 방식은 **본 과업 운영 범위에서 제외**하고, 현재 UX로 확정하였습니다.

### B-4. 잔여 과업

**제목:** 잔여 과업

**불릿:**
- 표준 테스트 시나리오 수행·보정 및 검수
- 시스템 구성·데이터 흐름·범위 합의 문서 정리
- (해당 시) 지식베이스를 관계형 DB·검색으로 구축한 내용의 대체 설명 정리
- 소스코드·DB 스키마·초기 데이터·백업·복구·배포 자료 인계

**발표 멘트(30초):**  
“기능 개발은 발주자 확정 범위 기준으로 완료했습니다. 시험과 함께 문서·인계를 정리해 검수에 대응하겠습니다. 벡터DB 등 문구상 항목은 현재 검색형 지식베이스로 대체·합의한 내용을 문서에 반영하겠습니다.”

### B-5. 표지/마무리용 짧은 문장

- 표지 부제: `기능 개발 완료 · 문서·시험·인계`
- 마무리: `합의된 기능은 개발을 마쳤습니다. 문서화와 인계로 과업을 마무리하겠습니다.`

## 공통 — 기능 플로우 슬라이드 (A/B 공통)

**제목:** KSIC 매핑 설문 생성 흐름

**단계:**
1. KSIC 코드 검색 · 연관 검색 · 분류표 선택  
2. 조사 목적 등 메모 입력  
3. 외부 KSIC 매칭 검증  
4. 업종 지식 조회(RAG형) → AI 설문 **3안** 생성  
5. 근거·보완 질문 확인 후 설문 채택

**캡션:** 발주자 확정 운영 방식
