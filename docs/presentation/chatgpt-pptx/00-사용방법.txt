================================================================================
ChatGPT로 버전 A / 버전 B PPTX 만들기 — 사용 방법
================================================================================

폴더 구성
---------
chatgpt-pptx/
  00-사용방법.txt          ← 이 파일
  버전A-ChatGPT전달.txt    ← 버전 A 전용 프롬프트 (통째로 붙여넣기)
  버전B-ChatGPT전달.txt    ← 버전 B 전용 프롬프트 (통째로 붙여넣기)
  images/
    01-system-architecture.png   시스템 구조
    02-business-flows.png        업무 흐름
    03-branching-logic.png       분기 로직
    04-data-and-modules.png      데이터·모듈

권장 순서
---------
1) ChatGPT(파일 업로드·PPTX 생성 가능한 모드)를 연다.
2) images 폴더의 PNG 4장을 모두 업로드한다.
3) 「버전A-ChatGPT전달.txt」 내용을 그대로 붙여넣고 실행 → 버전A.pptx 받기
4) 새 대화(또는 이어서)에서 PNG를 다시 올리고 「버전B-ChatGPT전달.txt」 실행 → 버전B.pptx 받기

참고
----
- 두 버전은 톤만 다르고, 삽입 그림(01~04)은 동일하다.
- KSIC 설문 생성 흐름 슬라이드는 제공 PNG가 없으므로, 프롬프트 지시에 따라
  ChatGPT가 도식(도형·화살표)으로 그리면 된다.
- 화면 캡처(관리자 AI설문 생성 UI)가 있으면 추가로 올려 “실제 화면” 슬라이드에 넣어도 된다.

파일명 요청
-----------
버전 A → ResearchHub_과업현황_버전A_개발완료-검수인계.pptx
버전 B → ResearchHub_과업현황_버전B_개발완료-문서인계.pptx
