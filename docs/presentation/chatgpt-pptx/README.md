# ChatGPT PPTX 생성용 패키지

버전 A·B 각각 PPTX를 만들 때 ChatGPT에 올릴 **전달 텍스트**와 **그림**을 모았습니다.

## 폴더

```
docs/presentation/chatgpt-pptx/
├── 00-사용방법.txt
├── 버전A-ChatGPT전달.txt
├── 버전B-ChatGPT전달.txt
└── images/
    ├── 01-system-architecture.png
    ├── 02-business-flows.png
    ├── 03-branching-logic.png
    └── 04-data-and-modules.png
```

## 사용

1. `images/` PNG 4장 업로드  
2. `버전A-ChatGPT전달.txt` 전체 붙여넣기 → A PPTX  
3. (새 대화 권장) PNG 다시 업로드 + `버전B-ChatGPT전달.txt` → B PPTX  

자세한 순서는 `00-사용방법.txt` 참고.

## 이미지 용도

| 파일 | 슬라이드 |
|------|----------|
| `01-system-architecture.png` | 시스템 구성 |
| `02-business-flows.png` | 업무 흐름 |
| `03-branching-logic.png` | 설문 분기·표시 조건 |
| `04-data-and-modules.png` | 데이터·모듈 구조 |

KSIC 설문 생성 5단계 흐름은 PNG가 없으며, 전달 텍스트에 따라 ChatGPT가 도형으로 그립니다.
