# 역할
당신은 공공·용역 검수 보고용 PowerPoint(PPTX)를 만드는 전문가입니다.
아래에 명시한 슬라이드 구성·문장·삽입 이미지를 지켜 **버전 B** PPTX 파일을 생성·다운로드 가능하게 제공하세요.

# 버전 B 톤 (필수)
- 메시지: 「발주자 확정 기능 범위는 개발 완료. 문서·시험·인계를 정리해 과업을 닫는다」
- 지시서·검수와 맞추는 신중한 톤. 과장(“무조건 100%”)보다 “합의 범위 완료”를 사용.
- 비정형→KSIC 코드 자동 추천은 “운영 범위에서 제외·현재 UX로 확정”으로 1장 명시.
- 벡터DB는 “미구현 결함”이 아니라, 잔여에서 “검색형 지식베이스 대체 설명 정리”로만 언급.

# 프로젝트 메타
- 용역명: AI(RAG) 기반 지능형 산업분류(KSIC) 자동 매핑 로직 및 기본 플랫폼 구축
- 제품/플랫폼: Research Hub
- 발주자: 프라임리서치
- 계약기간: 2026.7.22 ~ 2026.8.30
- 발주자 확정 UX: KSIC 검색·선택 → 메모 입력 → AI 설문 3안 생성(+ 무역보험공사 KSIC 검증)

# 슬라이드 구성 (이 순서·이 문구로)

---
## 슬라이드 1. 표지
제목: AI(RAG) 기반 KSIC 매핑 · 기본 플랫폼
부제: 개발 현황 보고
한 줄: 기능 개발 완료 · 문서·시험·인계
하단: Research Hub · 프라임리서치 · 2026.7.22–8.30

---
## 슬라이드 2. 과업 개요
제목: 과업 개요
3블록:
1) KSIC 데이터 구조화
2) RAG형 지식 활용 · 설문 생성
3) 기본 웹 플랫폼(입력·결과·관리)
하단: 구조화 → 검색·생성 → 운영·검증

---
## 슬라이드 3. 개발 현황 요약 (버전 B 핵심)
제목: 개발 현황 요약
본문:
• 발주자 확정 기능 범위의 개발을 완료하였습니다.
• KSIC 직접 선택 → 메모 입력 → AI 설문 3안 생성이 목표 운영 방식으로 확정·검증되었습니다.
• 잔여는 시험·검수, 구성·범위 문서 정리, 산출물 인계입니다.
하단 배너: 기능 개발 완료 · 문서·시험·인계 정리

---
## 슬라이드 4. 개발 완료 범위 (합의 기준)
제목: 개발 완료 범위 (합의 기준)
• KSIC 구조화·검색·선택 및 외부 코드 매칭 검증
• RAG형 지식 조회(업종 컨텍스트) 기반 설문 생성
• 복수 설문안(최대 3)·근거·보완 질문 제공
• 기본 플랫폼: 사업·조사 정보 입력, 결과 확인, 데이터 관리 화면
• 반응형 웹·형상관리(Git)·인증·입력 검증 등 기본 품질 요건

---
## 슬라이드 5. 운영 방식 확정 (버전 B 전용)
제목: 운영 방식 확정
본문:
• KSIC 코드는 검색·연관 검색·분류표로 관리자가 직접 선택합니다.
• 선택·메모 입력 후 AI가 산업 맞춤 설문지 3안을 생성합니다.
• 비정형 문장만으로 KSIC 코드를 자동 추천하는 방식은 본 과업 운영 범위에서 제외하고, 현재 UX로 확정하였습니다.

---
## 슬라이드 6. KSIC 매핑 설문 생성 흐름 (도형)
제목: KSIC 매핑 설문 생성 흐름
캡션: 발주자 확정 운영 방식
가로/세로 5단계 화살표:
1. KSIC 검색 · 연관 검색 · 분류표 선택
2. 조사 목적 등 메모 입력
3. 외부 KSIC 매칭 검증
4. 업종 지식 조회(RAG형) → AI 설문 3안 생성
5. 근거·보완 질문 확인 후 설문 채택
