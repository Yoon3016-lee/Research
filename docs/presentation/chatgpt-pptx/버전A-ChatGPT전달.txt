# 역할
당신은 공공·용역 중간/완료 보고용 PowerPoint(PPTX)를 만드는 전문가입니다.
아래에 명시한 슬라이드 구성·문장·삽입 이미지를 지켜 **버전 A** PPTX 파일을 생성·다운로드 가능하게 제공하세요.

# 버전 A 톤 (필수)
- 메시지: 「기능 개발 100% 완료. 남은 것은 검수·인계뿐」
- 자신감 있고 간결. 벡터DB·미구현 기능을 “미완”으로 강조하지 말 것.
- 시험 50건은 “잔여 과업”으로만 짧게 언급.

# 프로젝트 메타
- 용역명: AI(RAG) 기반 지능형 산업분류(KSIC) 자동 매핑 로직 및 기본 플랫폼 구축
- 제품/플랫폼: Research Hub
- 발주자: 프라임리서치
- 계약기간: 2026.7.22 ~ 2026.8.30
- 발주자 확정 UX: KSIC 검색·선택 → 메모 입력 → AI 설문 3안 생성(+ 무역보험공사 KSIC 검증)
