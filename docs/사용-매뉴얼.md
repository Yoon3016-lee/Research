## 1. 역할과 로그인

| 역할 | 공개 사이트 | 관리자 콘솔 |
|------|-------------|-------------|
| 비로그인(익명) | 설문 참여·문의 가능. AXI는 **권한 설정**에 포함된 경우만 | 불가 |
| 게스트 | 설문 참여, 마이페이지. AXI는 권한 설정에 포함된 경우만 | 불가 |
| 직원·팀장 | 설문 참여, CATI, (설정 시) AXI·응답 스크립트 | 불가 |
| 서브관리자 | 위와 동일 | 사용 가능 |
| 총관리자 | 위와 동일 | 사용 가능 + **홈페이지·가입키** 설정 |

### 1.1 공개 사이트에서 로그인·가입

헤더에 **로그인** / **회원가입** 버튼이 있습니다.

**로그인**

1. 「로그인」을 누릅니다.
2. 이메일·비밀번호를 입력합니다. (직원·게스트 계정 모두 동일)
3. 계정이 없으면 로그인 창 하단에서 선택합니다.  
   - **직원 회원가입** → 가입키가 필요한 관리자/직원 가입 페이지  
   - **게스트 회원가입** → 가입키 없이 게스트 계정 만들기

**회원가입**

- 헤더 「회원가입」또는 로그인 창의 「게스트 회원가입」→ 게스트 계정 생성
- 게스트 가입 창에서도 **직원 회원가입**으로 이동할 수 있습니다.

**설문 화면**에서도 「참여자 확인」으로 직원 로그인·게스트 로그인·게스트 가입이 가능합니다.

### 1.2 관리자 로그인

- 주소: `/admin/login`
- 최초 가입: `/admin/signup` + **관리자 가입키** (첫 가입자 = 총관리자)
- 가입키는 **권한 관리 → 가입키 설정**(총관리자)에서 변경합니다.

## 2. 공개 페이지

### 2.1 화면 구성

| 화면 | 주소 예시 | 하는 일 |
|------|-----------|---------|
| 홈 | `/` | 사이트 소개, 설문 참여 안내, 배너·팝업 |
| 설문 광장 | `/surveys` | 공개된 **진행중·예정** 설문 목록 |
| 설문 참여 | `/survey/설문주소` | 문항 응답·제출 |
| 제출 완료 | `/survey/설문주소/thanks` | 응답 완료 안내 |
| 안내·소개 글 | `/p/글주소` | 관리자가 등록한 CMS 콘텐츠 |
| 문의하기 | `/inquiry` | 조사·서비스 문의 접수 |
| 서비스 | `/services` | 참여 안내·FAQ·챗봇(**UI 데모**) |
| 마이페이지 | `/mypage` | 계정·진행 방식·비밀번호 (로그인 필요) |

상단 **탭 메뉴**는 총관리자가 **홈페이지 관리**에서 설정합니다.  
탭에 **안내 배너**(이미지·PDF)가 있으면, 해당 탭 하위 메뉴로 들어갔을 때 배너가 본문 바로 위에 표시됩니다.

### 2.2 설문 찾기와 참여

1. 홈 CTA 또는 상단 메뉴에서 **설문 광장**으로 이동합니다.
2. **진행중** 설문을 선택해 참여합니다.  
   **예정** 설문은 목록 안내만 가능하고, 기간이 시작되어야 참여할 수 있습니다.
3. 초대 링크(`/survey/설문주소`)로 바로 들어올 수도 있습니다.
4. 문항을 답한 뒤 제출하면 완료 화면이 표시됩니다.

**참고**

- 광장에 안 나와도, **진행중**이면 직접 링크로 참여할 수 있습니다.
- 예전 버전 주소로 들어오면, 가능하면 **최신 버전**으로 자동 연결됩니다.

### 2.3 참여자 유형별 차이

| 구분 | 비로그인·게스트 | 직원(로그인) |
|------|-----------------|--------------|
| 일반 문항 | 응답 가능 | 응답 가능 |
| 직원 전용 문항 | 보이지 않음 | 보임 |
| CATI(표본 조사) | 없음 | 활성 표본이 있을 때 |
| AXI | **기타 관리 권한**에 포함된 경우 | 동일(권한 설정) |
| 응답 스크립트 | 없음 | 직원 로그인 시 「스크립트 확인」 |

### 2.4 AXI (Advisor Agent)

공개 사이트 **우측 여백**에 드래그 가능한 아이콘으로 표시됩니다.  
(총관리자가 **홈페이지 관리 → 기타 관리**에서 **사용 권한**과 **아이콘**을 설정)

| 상황 | AXI 답변 방식 |
|------|----------------|
| 홈·설문 광장·문의·CMS 등 | **보편 안내** (사이트·조사 용어, KSIC 없음) |
| 설문 참여 화면 | 해당 설문의 **제목·KSIC·업종·스크립트·문항**을 참고 |

- 아이콘을 **클릭**하면 채팅 패널이 열리고, **드래그**하면 위치를 옮길 수 있습니다.
- 질문은 짧게, 답변은 보통 1~2문장입니다.

### 2.5 CATI (직원용)

표본 배치가 활성화된 설문에서 직원이 로그인하면:

1. **UID** 입력으로 표본을 불러옵니다.
2. **컨택 결과**(성공·부재 등)를 선택합니다.
3. 설문을 진행·제출합니다.
4. 필요하면 중도 초안을 저장할 수 있습니다.

### 2.6 문의하기

1. 「문의하기」 또는 `/inquiry`로 이동합니다.  
   - 조사: `/inquiry?type=survey`  
   - 서비스: `/inquiry?type=service`
2. 연락처와 내용을 남겨 접수합니다.
3. 관리자는 **문의 관리**에서 상태를 처리합니다.

### 2.7 마이페이지

로그인 후 `/mypage`에서:

- **설문 진행 방식**: 페이지 넘김 / 스크롤
- **비밀번호 변경**

## 3. 관리자 페이지

관리자 콘솔: `/admin`  
(총관리자·서브관리자만 접근)

---

### 3.1 대시보드 (`/admin`)

- 진행 중 설문·응답 수 요약
- 마감·시작이 가까운 설문 알림
- 자주 쓰는 작업으로 빠르게 이동

---

### 3.2 설문 관리 (`/admin/surveys`)

#### 목록 상단

| 기능 | 설명 |
|------|------|
| **새 설문 만들기** | 문항을 직접 작성 |
| **AI 설문 생성** | 목적·KSIC 등으로 문항·스크립트 초안 생성 |
| **스크립트 관리** | 공용 / 설문별 응답 스크립트 |
| **템플릿 불러오기** | 기존 설문 문항 복사 |
| **전체 컨택 관리** | CATI 컨택 결과 선택지(전역) |

#### 설문별 작업

| 작업 | 설명 |
|------|------|
| 참여 링크 | 진행중 설문 공개 URL |
| 표본 관리 | CATI 표본 엑셀·활성 배치 |
| 배포 관리 | 초대 문구·참여 URL (발송 API는 환경에 따라 준비 중일 수 있음) |
| 로직 확인 | 분기·직원 전용 흐름도 |
| 편집 | 제목·기간·문항 수정 |
| 삭제 | 응답·문항·표본 포함 삭제 (**되돌릴 수 없음**. 삭제 전 백업 권장) |

#### 만들기·편집

1. 새 설문 / AI / 템플릿으로 시작합니다.
2. 제목·요약·기간·목표 수·공개 여부·KSIC·응답 스크립트 등을 입력합니다.
3. 문항을 추가합니다. (객관식, 다중, 주관식, 리커트, 드롭다운, 순위, 안내 미디어 등)  
   분기·직원 전용·조사 종료 보기 등을 설정할 수 있습니다.
4. **저장**합니다.

#### 응답이 있는 설문 수정 (버전 분기)

응답이 **1건 이상**이면 저장 시:

1. **새 설문**(새 주소·새 문항 ID)이 만들어집니다. 편집 중 제목은 **새 설문**에 적용됩니다.
2. **이전 설문**은  
   - 제목에 **`(숨김)`** 이 붙고  
   - **종료·비공개**로 보존됩니다.
3. 기존 응답은 **이전 설문**에 그대로 남습니다.
4. 배포·초대 링크는 **새 주소**로 바꿔 주세요.  
   (구 주소로 들어오면 가능한 경우 새 버전으로 연결됩니다.)
5. 분기 직전 **응답 백업 스냅샷**이 자동으로 만들어집니다.

응답이 **없는** 설문은 같은 주소에서 바로 수정됩니다.

---

### 3.3 문의 관리 (`/admin/inquiries`)

1. 조사/서비스, 상태(접수·처리 중·완료·취소)로 필터합니다.
2. 상태·관리자 메모를 저장합니다.

---

### 3.4 권한 관리 (`/admin/permissions`)

| 탭 | 내용 |
|----|------|
| 직원 권한 | 역할 변경 (본인보다 낮은 등급만) |
| 가입키 설정 | **총관리자만**. 관리자 회원가입 키 |

---

### 3.5 진행·업무 현황 (`/admin/progress`)

1. 설문별 **목표 대비 진행도**를 확인합니다.
2. 「**응답 분석**」을 누르면 **해당 설문 카드 바로 아래**에 펼쳐집니다.  
   - **작업량**: 직원·게스트별 제출 수  
   - **문항별 응답 빈도**: **가로 막대 / 세로 막대 / 원형** 그래프 선택
3. 필요하면 응답 **엑셀 다운로드**를 사용합니다.
4. 「닫기」로 분석을 접습니다.

---

### 3.6 응답 백업 (`/admin/backups`)

| 종류 | 언제 | 용도 |
|------|------|------|
| **제출 아카이브** | 응답 제출 시마다 자동 | 설문별 아카이브 JSON |
| **전체 스냅샷** | 수동, 또는 버전 분기 직전 자동 | 스냅샷 JSON |

1. 설문 카드에서 아카이브·스냅샷 백업을 실행합니다.
2. JSON을 내려받아 보관합니다.

운영 DB에서 설문을 지워도, 받아 둔 JSON은 별도 보관본으로 남습니다.

---

### 3.7 홈페이지 관리 (`/admin/homepage`) — 총관리자 전용

| 탭 | 하는 일 |
|----|---------|
| **상단 메뉴** | 탭 추가·수정·삭제, 직링크, 탭별 안내 배너(이미지·PDF) |
| **사이트 설정** | 사이트명·폰트·로고, 하위 메뉴, CMS(`/p/...`) 본문 |
| **배너** | 상단 배너·팝업 배너 노출 설정 |
| **기타 관리** | **AXI 사용 권한**(체크박스) + **AXI 아이콘** 업로드 |

#### AXI 사용 권한 (기타 관리)

다음 대상을 체크해 AXI를 쓸 수 있는 사람을 정합니다.

- 비로그인 (`anonymous`)
- 게스트·일반 (`guest`)
- 직원 (`employee`)
- 팀장 (`team_lead`)
- 서브관리자 (`sub_admin`)
- 총관리자 (`super_admin`)

기본값은 **직원 이상**(employee ~ super_admin)입니다.  
하나 이상 선택한 뒤 **권한 저장**을 누릅니다.

## 4. 자주 쓰는 시나리오

### A. 새 설문을 만들고 공개하기

1. **설문 관리** → 새 설문(또는 AI·템플릿)
2. 기간·목표·문항 작성 후 저장
3. **진행중** + 필요 시 공개 목록 표시
4. **배포 관리**에서 참여 URL 공유

### B. 게스트가 공개 사이트에서 가입하기

1. 헤더 **로그인** → 「게스트 회원가입」  
   또는 헤더 **회원가입**
2. 이메일·비밀번호로 가입
3. 이후 동일 계정으로 로그인하면 게스트 작업량에 집계됩니다.

### C. CATI 전화 조사

1. **표본 관리**에서 엑셀 업로드·배치 활성화
2. **전체 컨택 관리**에서 컨택 선택지 확인
3. 직원이 공개 사이트에서 해당 설문에 로그인
4. UID → 컨택 결과 → 응답

### D. 응답이 쌓인 뒤 설문 수정

1. (권장) **응답 백업**에서 스냅샷 확보
2. 설문 **편집** 후 저장 → 새 버전 생성, 이전은 `(숨김)`·종료
3. 배포 링크를 **새 주소**로 교체
4. 이전 응답은 이전 설문·진행 현황·백업에서 확인

### E. 응답 분석

1. **진행·업무 현황** → 「응답 분석」
2. 그래프 종류를 바꿔 문항별 빈도 확인
3. 엑셀·백업 JSON으로 내보내기

### F. AXI를 게스트·비로그인에게도 열기

1. **홈페이지 관리 → 기타 관리**
2. AXI 사용 권한에서 원하는 대상 체크 후 저장
3. 공개 사이트에서 해당 사용자에게 아이콘이 보입니다.

## 5. 알아두면 좋은 규칙

1. **응답 있는 설문 수정 = 새 버전**  
   이전 제목에는 `(숨김)`이 붙고, 응답은 이전 설문에 보존됩니다.

2. **삭제**  
   설문 삭제는 응답·문항·표본까지 지우며 되돌릴 수 없습니다. 삭제 전 **응답 백업**을 권장합니다.  
   (응답이 있어도 삭제 가능하도록, 답변→응답→설문 순으로 정리합니다.)

3. **직원 전용 문항**  
   게스트·비로그인에게는 보이지 않습니다.

4. **예정 vs 진행중**  
   광장에는 둘 다 보일 수 있지만, **참여는 진행중**일 때만 가능합니다.

5. **AXI**  
   공개 사이트 전역에서 동작하며, 설문 안에서는 KSIC·스크립트를 참고합니다.  
   누가 쓸지는 **기타 관리** 권한으로 정합니다.

6. **서비스 페이지**  
   `/services` 챗봇·안내는 UI 데모일 수 있습니다. 실제 문의는 **문의하기**를 사용하세요.

7. **배포 이메일·문자**  
   문구·링크 준비까지는 가능하고, 실제 발송은 환경에 따라 준비 중일 수 있습니다.
